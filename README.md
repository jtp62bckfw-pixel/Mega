# MEGA Panel starter

واجهة تجريبية أولية لمشروع MEGA.

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`
3. عيّن متغير `SESSION_SECRET` بقيمة طويلة وعشوائية.
4. نفّذ `npm start`

## ملاحظات مهمة
- هذه نسخة بداية وليست منصة بيع خدمات مكتملة.
- لا يوجد ربط بمزوّد خدمات أو دفع حقيقي أو شحن TON.
- لا تستقبل أموالًا قبل إضافة مزود دفع موثوق واختبار النظام وتأمينه.
- عند النشر، أضف `SESSION_SECRET` في إعدادات الاستضافة ولا تستخدم القيمة الافتراضية.
